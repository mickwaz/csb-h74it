# Static Template

This is a static template with no bundling - perfect for simple web projects!

## Getting Started

1. Clone this repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm start
   ```
4. Open your browser and navigate to the provided URL

## Project Structure

```
├── index.html          # Main HTML file
├── package.json        # Project dependencies and scripts
├── README.md          # This file
└── .gitignore         # Git ignore rules
```

## Development

- Edit `index.html` to modify the main page
- Add CSS files and link them in the HTML
- Add JavaScript files and include them in the HTML
- The `serve` package will automatically serve your files

## Scripts

- `npm start` - Start the development server
- `npm run build` - Display build information (no bundling required)
